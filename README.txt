АЛЬТАИР — развивающая игра для iPhone

Публикация (бесплатно):
1. Создайте на GitHub новый публичный репозиторий altair-kids (или отдельную папку на вашем сайте).
2. Загрузите все файлы из этого архива в корень репозитория.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Откройте появившийся HTTPS-адрес в Safari на iPhone.
5. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
6. Откройте и один раз загрузите игру с интернетом. Затем интерфейс и игры доступны офлайн.

Примечание: озвучка работает через системный синтез речи iOS и зависит от установленных голосов.
Ни рекламы, ни покупок, ни аналитики, ни сторонних библиотек.
